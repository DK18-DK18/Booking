
# Enterprise Management System

A professional enterprise dashboard built using HTML, CSS and JavaScript.

## Features

- Modern enterprise dashboard
- Responsive sidebar navigation
- Setup module
- Admin module
- Import module
- Export module
- Reports module
- Custom module
- Finance module
- AGS module
- Search functionality
- CSV import preview
- CSV sample export
- Responsive mobile layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Lucide Icons

## Project Structure

enterprise-dashboard/
|
|-- index.html
|-- style.css
|-- script.js
|-- README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## GitHub Pages

## Note

Dashboard statistics are sample data.
The application currently uses frontend-only functionality.
A backend and database are required for permanent data storage,
authentication and real enterprise operations.
